# وب‌سایت تهویکا — نسخه اولیه

این پوشه نمونه اولیه صفحه اصلی وب‌سایت خدمات تأسیسات است.

- نام «تهویکا» موقت است و بعداً بدون تغییر ساختار قابل جایگزینی است.
- ساختار صفحه بر اساس خوشه‌های خدمات، صفحات عیب‌یابی، پروژه‌ها و سرویس دوره‌ای طراحی شده.
- اطلاعات تماس و دامنه فعلاً placeholder هستند.
- مرحله بعد: ساخت صفحات مادر خدمات و سپس زیرصفحه‌های سئو برای هر خدمت/مشکل.
