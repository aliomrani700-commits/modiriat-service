# مدیریت سرویس (Modiriat Service)

سیستم مدیریت خدمات برای ایجاد پرونده کامل مشتری.

## امکانات هدف

- پرونده کامل مشتری
  - اطلاعات تماس
  - فاکتورها
  - پرداخت‌ها
  - سابقه خدمات
  - زمان سرویس بعدی

- صدور فاکتور و ارسال برای مشتری
- یادآوری سرویس دوره‌ای با پیامک
- پشتیبان‌گیری از اطلاعات
- نسخه موبایل (Android)

## نقشه ساخت

مرحله اول:
- طراحی دیتابیس مشتری، خدمات، فاکتور و پرداخت
- ساخت هسته برنامه

مرحله دوم:
- رابط کاربری موبایل
- مدیریت پرونده مشتری

مرحله سوم:
- پیامک یادآوری
- بکاپ و بازیابی

پروژه در حال توسعه است.
